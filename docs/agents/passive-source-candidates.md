## Current outcome

Kimi Code (`kimi_code`), Pi (`pi`), Oh My Pi (`omp`), Grok Build (`grok`), ZCode (`zcode`), Antigravity CLI (`antigravity`), and DeepSeek Harness (`deepseek_harness`) have passed the passive-reader gate. They use sanitized fixtures, sync-twice and rewrite/append coverage, source-scoped cursors, explicit token-quality contracts, and privacy-bounded normalization. Grok is `precise` and `unpriced`: the primary path is `turn_completed` `params.update.usage`; sessions without usage keep the older total-only fallback. The catalog has no grok row, and `costUsdTicks` is not used. Antigravity CLI conversations are imported; hook-era unattributed rows stay queryable and rebuild-protected. The IDE-side `.pb` family stays planned. Reasonix and the remaining candidates stay monitor-only; `llmusage source-status` may report their roots and blocked parser state, but sync must not write usage rows for them.
