# IDE native SQLite design — accepted implementation

## D1 Discovery and decode (R1)
Use ~/.gemini/antigravity-ide/conversations/*.db and the sibling native CLI root under existing GEMINI_CLI_HOME. Do not add configuration, RPC, credential reads or .pb decryption. Old antigravity/backup roots are excluded. Share the CLI decoder and its installed-descriptor/native-fixture oracle; positive cache-write has schema-based evidence only.

## D2 Ownership (R2)
Resolve both roots before filtering. trajectory_meta.source17CLI/1IDE provides native product provenance even across copied roots and outranks fallback directory attribution. Unknown/conflicting explicit product metadata blocks the affected snapshot. Canonicalize aliases and historical paths; normalize request identities to remove gen/step/copy mirrors, preserving independent retry attempts.
Use one persisted group hash per product and complete group replay. Cross-product history transfers require both products selected and one unbounded transaction. Incomplete group input retains history. Include cursor and source_file membership, including forgotten rows and bounded-first imported files, so absence never authorizes implicit deletion.

## D3 Lifetime and safety (R3)
Read only usage/model/time/identity/workspace/product metadata in read-only SQLite transactions. DB+WAL fingerprints trigger replay; changing files retry without clearing history. Bounded imports carry membership but no reset/full cursor. Explicit rebuild uses the shared staged transaction and missing-file guard; hooks remain historical facts.
Fresh remote v3 imports are host-isolated. Old remote accounting remains refused; remote restoration is not added. Windows native reconciliation is against unchanged oracle fingerprints because the IDE continues writing; other platforms remain live-UNVERIFIED.

## D4 Consumers (R4)
User approved additive SourceKind::AntigravityIde, stable ID antigravity_ide, focused command antigravity-ide. Keep antigravity for CLI and both markers3. Register descriptors, monitors, parser, filters, home series, TUI/Web/Desktop badges and pricing-source matching. CLI readiness never implies IDE readiness. Token diagnostics and unpriced costs remain distinct.
Update bilingual README/docs, ADR0017, source/token contracts and passive-source candidates. Validate native fixtures, sync safety, remote guards, consumer projections and just ci; do not commit/push/archive without a separate request.
